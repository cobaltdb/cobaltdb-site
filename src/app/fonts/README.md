Local variable fonts from the upstream Google Fonts collection, distributed under
the accompanying SIL Open Font License files. Converted losslessly from TTF to
WOFF2 with FontTools. Both files include Latin Extended and Turkish glyphs.

- Space Grotesk: https://github.com/google/fonts/tree/main/ofl/spacegrotesk
- JetBrains Mono: https://github.com/google/fonts/tree/main/ofl/jetbrainsmono

Loaded centrally through `next/font/local`. Space Grotesk is the UI and prose
family; JetBrains Mono is for code and technical labels. Quicksand is reserved as
a semantic token and is not downloaded because the current design has no accent
area that needs a third font.
